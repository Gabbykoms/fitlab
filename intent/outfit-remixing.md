# FitLab: Combine and refine outfits

Status: Draft — pending team review.
Named team approver: Pending.

## Purpose

Let users build a preferred outfit from the generated options and refine it through written requests.

## User experience

After seeing three options, the user can select a complete look or combine individual pieces from different looks. For example, choose the shirt from option one and the trousers from option three, then request: "Keep the trousers, swap the jacket."

The app generates an updated mannequin image reflecting the selected combination and requested changes. The original occasion, styling preference, and event weather remain part of the brief unless the user changes them.

## Success criteria

- Users can select pieces from more than one generated option.
- The chosen combination is visible before generating its updated image.
- Users can submit written changes and see an updated look.
- Requests to preserve selected pieces are included in the revision brief; visual fidelity is checked rather than assumed.
- Updated images receive a fresh vision critique against the revised brief.

## Open decisions

- Clothing categories and rules for conflicting selections.
- Whether to retain previous revisions for comparison in the first version.
